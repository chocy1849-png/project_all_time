## 저장과 재실행 확인

1. S001을 진행해 배경, 인물과 아침 음악이 나오는지 확인합니다.
2. Save를 열고 빈 수동 슬롯에 저장합니다. 대사 내용과 슬롯 번호를 기록합니다.
3. 여러 문단 진행한 뒤 Load에서 같은 슬롯을 불러옵니다. 저장한 문단이 표시되는지, 한 번 진행하면 올바른 다음 문단이 나오는지 확인합니다.
4. 게임을 정상 종료하고 같은 실행 파일을 다시 엽니다. 저장 슬롯이 남아 있고 불러올 수 있는지 확인합니다.
5. QA 저장 폴더 `%USERPROFILE%\AppData\LocalLow\ProjectAllTimeQA\AllTime_M10_13_PlayGate\SaveData`에 파일이 생겼는지 확인합니다. 이 폴더에는 이미 QA 수동 및 자동 슬롯이 있으므로 덮어쓰지 않을 빈 슬롯을 선택해 주세요.

S004의 수동 대기에서 자동/스킵이 멈추고 직접 진행하면 계속되는지도 확인해 주세요. S008에서는 세 프로필을 살펴보고 첫 검토 때의 생각, 하나 선택, 이후 대화가 이어지는지 살펴봐 주세요. Records에서는 기록과 리플레이를 열고 완료와 취소를 확인합니다.
