# 프롤로그 플레이 테스트 안내

상태: 빌드 검증 진행 중. 저장/불러오기 및 재실행 확인이 끝나기 전에는 플레이 게이트 준비 완료로 간주하지 않습니다. 사용자 수락이나 출시 허가는 아직 기록되지 않았습니다.

1. Build 폴더의 AllTime_M10_13_PlayGate.exe를 더블 클릭합니다. 또는 Run_PlayGate.ps1을 PowerShell로 실행하면 로그가 Logs/Player.log에 기록됩니다.
2. 시작하면 S001 프롤로그가 나옵니다. 스페이스 또는 마우스 왼쪽 버튼으로 대사를 진행하고 하단 버튼에서 자동, 스킵, 숨기기, 백로그, 저장, 불러오기, 설정과 기록을 확인해 주세요.
3. S004에서 수동 진행 구간은 자동/스킵이 넘기지 못해야 합니다. 직접 진행한 뒤 다시 저장해 보세요. S008에서는 세 프로필을 살펴보고 첫 검토 때 나오는 생각과 하나 선택 후 대화가 이어지는지 확인해 주세요.
4. 기록 화면에서 타임라인과 리플레이를 열고 완료 및 취소를 확인해 주세요. 저장은 빈 수동 슬롯을 선택하고, 다른 대사로 진행한 뒤 불러와 정확한 대사와 다음 대사를 확인해 주세요.
5. QA 저장과 진행 기록은 %USERPROFILE%\AppData\LocalLow\ProjectAllTimeQA\AllTime_M10_13_PlayGate 아래에 있습니다. 테스트 진행을 초기화하려면 게임을 완전히 종료한 후 이 QA 전용 폴더의 이름을 AllTime_M10_13_PlayGate_보관 등 새 이름으로 바꾸세요. 같은 이름이 이미 있다면 다른 이름을 쓰세요. 일반 게임 폴더는 건드리지 마세요.
6. 문제가 생기면 장면(S001~S008), 보이는 대사, 직전 조작, 기대한 결과와 실제 결과를 알려 주세요. Windows 캡처 도구 또는 Win+Shift+S로 화면을 캡처해 전달할 수 있습니다. Logs/Player.log가 있으면 함께 전달해 주세요. 스크린샷은 Evidence 폴더에 저장해도 됩니다.

각 장면에서 화면 배치와 한글 가독성, 대사의 호흡, 음악과 효과음의 크기 및 타이밍을 살펴보고 불편한 점을 알려 주세요. S006의 기계 로프는 임시 이미지이고 다섯 효과음은 임시 무음입니다. 이를 최종 콘텐츠로 승인한 것으로 간주하지 않습니다.
