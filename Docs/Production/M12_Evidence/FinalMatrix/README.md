# M12 Game View capture matrix

Captured from the actual production `VN_Main` scene in Unity Editor Play Mode through Unity Pipeline Game View capture. The 36 PNGs cover the 12 required UI states at exact 1280×720, 1600×900, and 1920×1080 Game View sizes. These are composited runtime captures, not mockups.

The Continue-enabled, S001, and restored-gameplay states used the isolated temporary Editor data root `%TEMP%\M12_final_matrix_590a04a680dd4a6d81f08f870220383e`; no real user SaveData was used. Settings and MetaProgress were isolated for the scene run.

Load/Settings/Records show their existing M7/M9 screens. Their full redesign is deferred to M13.
