The latest full unfiltered EditMode run passed **593/593**, including the 13 M13-04 tests. The new integration tests use an isolated temporary repository and production modal/controller wiring. They cover selection without writing, actual empty-slot save, overwrite prompt/cancel/confirm and JSON/thumbnail preservation on cancel, target isolation, stale selection across pages, Auto read-only behavior, protected corrupt/unsupported records, Title Load restriction, confirmation input shielding and thumbnail suppression restoration. Existing tests cover repository, serialization, thumbnails, quick operations, M12 restoration and M13-03 font integrity. Coverage of all original requested transaction permutations is not claimed.

The test now sets it for its Play Mode fixture and restores the prior value in a `finally` block; the focused rerun and final full regression passed. No timeout was increased and no assertion was removed.
