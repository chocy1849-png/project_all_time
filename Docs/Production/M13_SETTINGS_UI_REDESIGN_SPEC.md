# M13-03 Settings redesign specification — refined

Production scene: `Assets/_Project/Scenes/VN_Main.unity`, under the original `VNCanvas/ModalLayer/SettingsModal/Panel`. The existing five views, `VNSettingsPanel`, settings service, six `VNRebindItem` instances, slider commit seams, rebind service and modal controller retain authority. No extra EventSystem or input capture system is introduced.

The local `Docs/DesignReferences/M13_Settings_Concept/M13_Settings_Design_Concept_Package` HTML and its twelve images are the reference. The production view uses an identity header, selected teal navigation, category title and description, grouped rows, aligned control and value columns, and a diagnostic footer. Display preserves TMP dropdowns and actual mode/resolution data. Text and Audio retain original Sliders and same-object `VNSettingsSliderCommit`; shared Slider visuals remain nested. Gameplay keeps the original Toggles: `VNSettingsSwitchVisual` reads their state, including `SetIsOnWithoutNotify`, and displays pill/round-thumb position and Korean on/off text. Controls uses two subviews: six editable two-column binding cards and a read-only six-action guide. The guide obtains the current strings from the existing rebind service; it adds no actions and does not invent shortcuts. Switching to the guide cancels any active rebind via the existing owner.

`M13SettingsSceneBuilder` delegates to `M13SettingsRefinement`; generated presentation objects are rebuilt idempotently while authoritative view/controller objects and serialized references remain. Two consecutive applications were checked in the Editor: 292 transforms before and after, one guide, six rebind items, six sliders and valid panel wiring. The original shared Slider/Toggle visuals and M13 Direction B assets are reused; a separate theme manager is not added.

Pretendard v1.3.9 is from the official `orioncactus/pretendard` release `Pretendard-1.3.9.zip`, 47,304,526 bytes, SHA-256 `04be351a74d6bf7d60c480a3087e51d185485d35a52023142af1df19eb8c428a`; ZIP CRC verification reported no bad entry. The release did not publish a digest in its GitHub asset metadata, so the recorded SHA is an acquisition fingerprint, not an independently verified publisher checksum. Regular, Medium and SemiBold static OTFs and the original SIL OFL 1.1 notice are in `Assets/_Project/Fonts/Pretendard`. Three dedicated dynamic multi-atlas TMP assets use those source fonts with `M13_Shared_Korean_SDF` as fallback; clear-dynamic-data-on-build is set. They affect Settings only. The existing global font and its dynamic cache were not committed.

Differences from the concept: the static illustrative dialogue preview and unverified fixed shortcut examples are omitted; the guide shows only the six real configurable actions. Navigation icons and the concept's decorative help panels are omitted. The layout uses the project's CanvasScaler and its existing modal rather than a separate preview canvas. These choices preserve the production data and input contracts; final visual acceptance belongs to the user.
