# M13-02 shared UI validation report

Unity 6000.3.21f1, 2026-11-16. The seven prefabs were generated by `M13SharedPrefabBuilder` using Unity Editor APIs. The focused EditMode run completed with **15 passed, 0 failed, 0 skipped**. The subsequent unfiltered EditMode run completed with **563 passed, 0 failed, 0 skipped**. These are fresh results, not the historical baseline.

The focused tests load every prefab, check missing scripts and Image/TMP references, verify the theme reference, card content and locked interaction state, independent tab selection/focus and focus suppression on disabling, source font glyph availability, standard Slider and Toggle values, and Scrollbar normalized values. Programmatically delivered pointer click, submit, move, wheel and drag events exercised Button, Toggle, Slider, Scrollbar and a ScrollRect fixture; the wheel test checks content movement and scrollbar synchronization. These are automated event tests, not physical input tests.

The editor demo (`Tools > M13 > Open shared component demo`) instantiates the actual prefabs on a Canvas and connects a card list to a ScrollRect and the shared Scrollbar. Camera-rendered Game View captures were inspected at [1280×720](M13_Evidence/M13_02/m13_verified_720.png), [1600×900](M13_Evidence/M13_02/m13_verified_900.png), and [1920×1080](M13_Evidence/M13_02/m13_verified_1080.png). They show the normal, focused/selected and locked cards, Korean text, a selected/focused tab, slider, off toggle and scrollbar. The lower card is intentionally clipped by the scroll viewport. A prior capture revealed missing Korean characters in the global font; the implementation was changed to a dedicated dynamic multi-atlas font with the tracked Korean source, and the listed captures show the representative text after that change. The screenshot thumbnail uses a project-owned sprite.

The captures do not prove every string fits or every device/input configuration works. Physical mouse and keyboard interaction, extreme localized text lengths, toggle-on and destructive variants in a production screen, and additional aspect ratios still require integration-specific verification. No existing persistence, modal arbitration or production screen was changed. The pre-existing modified global Noto asset and unrelated untracked evidence were excluded from the implementation commit.
