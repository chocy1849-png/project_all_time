# M13 UI asset production — working report

**Incomplete; user visual approval remains separate.** The current scenes are isolated prototypes; this report does not claim M13-00/01 acceptance.

## Assets and reproducibility

`AgentScripts/generate_m13_ui_assets.py` produces 22 original 128×128 RGBA PNGs: `A_` and `B_` variants of panel, secondary, card, inset, button, selected, tab, track, handle, focus and grain. Shapes, lighting and seeded noise are procedurally authored; no commercial-game graphics were imported. A separate temporary-directory regeneration matched all 22 SHA-256 hashes on 2026-11-16. Existing project-owned background imagery is used only for preview content.

Unity 6000.3.21f1 importer: Sprite Single, Full Rect, bilinear, clamp, no mipmaps, uncompressed and alpha transparency. Grain has zero border; button/tab/selected/handle use 12 pixels; remaining structural sprites use 20 pixels. `Image.Type.Sliced` is used for scalable surfaces; a separate low-opacity Tiled grain Image avoids stretching panel-center noise. The current preview uses solid uGUI tracks instead of the generated track PNG. These settings passed 4 focused A/B importer and prefab tests; that does not establish visual correctness at every size.

The [A size experiment](M13_Evidence/NineSliceTests/A_sizes.png) is a real screen capture from a temporary Play-mode uGUI overlay. Top to bottom: panel 240×100 and 1100×150, card 180×100 and 600×170, button 70×32 and 480×80, tab 90×32 and 540×80, in reference units. Corners appeared continuous in this 1080p example. B, other aspect ratios and controls still need dedicated inspection.

## Font and preview

`M13_Preview_Korean_SDF.asset` is an isolated static TMP atlas generated by `M13StylePreviewBuilder` from project-owned `NotoSansKR-Regular.ttf`, populated with the fixture's Korean, Latin, numerals and punctuation. All current A/B label strings passed glyph-table checks. After an Editor restart and forced asset reimport, A prefab labels again reported no missing glyphs. It is intentionally limited to fixture text and must not be substituted globally for production Korean. No incidental production Noto cache update is included.

A/B use the same uGUI composition, CanvasScaler, project background and representative data. The current state includes an image preserving aspect ratio, selected tab plus focus ring, disabled and destructive button, Slider, Toggle and a ScrollRect linked to a Scrollbar. A startup helper restores the list to top after layout. A programmatic Unity UI event check changed slider 0.65→0.75, toggled true→false and moved scroll content 0→280; specific physical pointer and keyboard checks are recorded below; they do not cover every path. Preview data has no SaveData integration.

## Evidence and observations

See [current capture index](M13_Evidence/Current/README.md) and [baseline index](M13_Evidence/Before/README.md). A has cooler gray edges; B uses warmer charcoal and gold edges. A is the working recommendation for continuity and restrained surfaces, subject to review and remaining tests. Tiled overlay opacity was reduced from the rejected noisy experiment and sampled 1080p captures show a quieter result. The screenshots do not prove lack of tile repetition at every scale or background.

At actual 1080p over the bright background, a rough sRGB screenshot sample used the 25th percentile background and 99th percentile pixel luminance in text bounding boxes. Estimated ratios: card title 7.40:1, metadata 5.14:1 after brightening (prior sample 3.94:1), hint 4.58:1, disabled label 5.32:1. Anti-aliasing, box selection and no independent foreground/background segmentation limit these estimates. Other states, backgrounds, indicators and smaller sizes require measurement; no comprehensive WCAG pass is claimed.

Focused `M13PreviewTests`: 5 passed after fixing a test's null diagnostic formatting; tests cover import settings, prefab references/glyph coverage, and programmatically delivered focus/control events. Full unfiltered EditMode run after the latest implementation change: **546 passed, 0 failed, 0 skipped, 0 inconclusive**. No Windows Player visual test was run. The production scene was captured with isolated company/product persistent storage; production scene and runtime files were not edited.
