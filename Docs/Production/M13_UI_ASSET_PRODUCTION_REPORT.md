# M13 UI asset production — working report

**Incomplete; user visual approval remains separate.** The current scenes are isolated prototypes; this report does not claim M13-00/01 acceptance.

## Assets and reproducibility

`AgentScripts/generate_m13_ui_assets.py` produces 22 original 128×128 RGBA PNGs: `A_` and `B_` variants of panel, secondary, card, inset, button, selected, tab, track, handle, focus and grain. Shapes, lighting and seeded noise are procedurally authored; no commercial-game graphics were imported. A separate temporary-directory regeneration matched all 22 SHA-256 hashes on 2026-11-16. Existing project-owned background imagery is used only for preview content.

Unity 6000.3.21f1 importer: Sprite Single, Full Rect, bilinear, clamp, no mipmaps, uncompressed and alpha transparency. Grain has zero border; button/tab/selected/handle use 12 pixels; remaining structural sprites use 20 pixels. `Image.Type.Sliced` is used for scalable surfaces; a separate low-opacity Tiled grain Image avoids stretching panel-center noise. The current preview uses solid uGUI tracks instead of the generated track PNG. These settings passed 4 focused A/B importer and prefab tests; that does not establish visual correctness at every size.

The [A size experiment](M13_Evidence/NineSliceTests/A_sizes.png) is a real screen capture from a temporary Play-mode uGUI overlay. Top to bottom: panel 240×100 and 1100×150, card 180×100 and 600×170, button 70×32 and 480×80, tab 90×32 and 540×80, in reference units. Corners appeared continuous in this 1080p example. B, other aspect ratios and controls still need dedicated inspection.

## Final geometry, visual, and interaction pass — 2026-11-16

The preferred Direction B material is retained. The scrollbar issue was corrected as a layout/input-lane change: the card viewport is narrower, the pointer lane is reserved beside it and outside its mask, and the visual thumb is narrower than both its rail and its transparent drag region.
